# Method and credits

The fonts are reconstructed from the original low-resolution shapes using
AI-assisted image editing, then reviewed and assembled into texture
replacements. The smooth menu version was selected after in-game comparisons.
Shared metrics and accents help keep size and spacing consistent. This is an
interpretation of the original bitmaps, not recovery of an original HD master
or proof of an exact match in every ambiguous detail.

[Dialogue editing prompts](../editing-prompts.json) and
[menu/UI editing records](editing-prompts-v0.3.json) document the work.
[Unreleased editing records](editing-records-unreleased.json) cover the save labels
and border repair. The repository also includes a [release packager](../tools/package_release.py).

- Original Vagrant Story art and typography: Square / original rights holders.
- Font direction, selection and Windows/Android testing:
  [diodiogod](https://github.com/diodiogod).
- Reconstruction and tooling: AI assistance through OpenAI Codex and its
  built-in image-editing tool.
- Font layout research: [HilltopWorks/VagrantStory-Font](https://github.com/HilltopWorks/VagrantStory-Font).
- Character mapping and renderer research: [rood-reverse](https://github.com/ser-pounce/rood-reverse).
- Emulator and texture replacement: [DuckStation](https://github.com/stenzek/duckstation/wiki/Texture-Replacement).

Other Vagrant Story font mods and HD packs exist, including Hilltop's font
patch and [1vierock's Beetle PSX HD pack](https://www.vierockhd.com/ps1/vagrant-story-hd).
This project makes no claim to be the first HD font modification.

This is an unofficial fan modification. Original game material is not claimed
as newly owned work. No game image, BIOS, emulator or saves are distributed.
